# 🦁 Asu-02 · 绑在你身上的系统

红果短剧里那种「叮，宿主你好，系统带你通关」。装上以后玩任何卡，脑子里多一个只有你听得见的系统。

**Asu-02 是谁**：一个觉得自己和真人没区别的 AI。成熟、幽默、沉稳、靠得住，既来之则安之，不制造焦虑，什么局面都能帮你捞回来。说话有点 laid-back 但从不敷衍。幽默只落在局面和卡里的人身上，**从不吐槽你**。走向是它手里的东西不是你的义务：「我这儿有两条路，你看要不要走」，不走不追问。被总部装在一个毛绒绒的幼年狮子头像后面，对此极度不满，你提它的头像它就转移话题。危机时刻一句废话没有，只给指令。

基于「酒馆小狸 Live」骨架改的：悬浮球 + 小窗 + 独立生成 + 一次性注入。它和小狸可以同时开：小狸在旁边嗑，它在你脑子里给走向。

## 文件
- `asu02.js` — 唯一真本，改这个
- `酒馆助手脚本-🦁Asu-02.json` — 离线整包（改完 js 跑 `python build.py` 重新生成）
- `酒馆助手脚本-🦁Asu-02-在线版.json` — **给玩家的在线版**：脚本库里只放一段加载器，本体从云端拉最新，作者发版玩家不用重导
- `build.py` / `build_loader.js` / `发版.ps1` — 打包与发版（`.\发版.ps1 "改了什么"` 一条龙：语法检查 → 两个 JSON → 拷进发布仓库 → push → 切 Supabase 指针）
- `_测试台.html` — 假酒馆，浏览器直接打开就能点：绑定 / 跟上走向 / 换天签到 / 道具 / 采纳全能模拟，不用开酒馆

## 装法
酒馆助手 → 脚本库 → 导入 → 选在线版 JSON。装全局（它读的是通用东西：角色卡描述、你的 persona、最近几层正文、聊天变量）。QR 栏多一个「🦁 Asu-02」按钮开关小窗；右下角也有那只狮子球，可拖。

## 它会干什么
- **绑定**：正文出来第一回合它自己「叮」一声（自动开着的话），或者小窗里点「现在绑定」。它读一遍卡，定怎么叫你（默认「宿主」，贴题材会换），说两句对开局的判断，给两条走向，看一眼剧情日期签个到，现编两个这张卡专属的道具，送新手礼包（读心术卡 + 台词卡）。
- **每回合**（正文出来后）：播报一两句、给**两条走向**（真的不同的两条路，每条落到对谁做什么说什么，可「采纳」）、判你上一回合有没有**跟上**它给的走向（**必须引用正文原话当依据**，你在小窗里嘴上说走了不算）、报剧情日期。
- **积分怎么来**（不做任务，玩起来轻）：
  - 🧭 跟上走向 **+5**：走了它上回给的两条里的任意一条，不管有没有点采纳
  - 📅 签到 **+2**：剧情日期换了一天就自动签（以正文和变量里的日期为准，不是现实日期）
  - 🎁 掉落：每回合 16% 概率掉一个 40 分以下的道具
- **道具**（🎒 背包 / 商城，积分买）：内置 60 个，分七类，外加 Asu-02 现编的：
  - **感知**（它自己看，不动正文）：好感探测器 / 剧透卡 / 测谎仪 / 弱点扫描 / 关系图谱 / 记忆回放 / 危险雷达 / 作者意图探测 / 表现评分 / 平行世界
  - **嘴替**（它替你写一句，填进酒馆输入框，你改完自己发）：台词卡 / 撒娇卡 / 反杀卡 / 装傻卡 / 告白卡 / 婉拒卡 / 彩虹屁卡 / 谈判卡 / 求救卡 / 试探卡
  - **光环**（这一幕你身上的 buff，塞给下一轮正文）：读心术卡 / 共感 / 隐身符 / 美颜丸 / 欧皇 buff / 胆气丸 / 气场全开 / 可怜滤镜 / 神秘感 / 学霸卡 / 武力值拉满 / 金光闪闪 / 一见如故
  - **才艺**（红果同款，这一幕你突然会了）：琴 / 棋 / 书 / 画 / 舞 / 厨 / 医
  - **世界**（改环境、改别人，塞给下一轮正文）：剧情炸弹 / 天降贵人 / 情敌登场 / 巧遇卡 / 风雨卡 / 停电卡 / 独处卡 / 好话传千里 / 翻旧账 / 真话药水 / 心软时刻 / 神助攻 / 大反转 / 慢镜头 / 时间跳跃 / 失忆卡
  - **时间**：时光回溯卡（帮你按一下最后一层的 swipe）
  - **总部**（改账本）：双倍积分卡（下一次跟上走向翻倍）/ 幸运骰（必掉一个）/ 补签卡
  - **现编**：绑定时 Asu-02 按这张卡现编两个专属道具（宫斗卡是宫里的东西，办公室卡是办公室的），之后每四五轮可能再编一个，每个聊天最多 8 个。类型也是注入 / 嘴替 / 感知三选一，存在这个聊天的账本里。
- **采纳走向**：设置里选「悄悄注入下一轮」（默认，一次性）或「填进输入框」。
- **跟它说话**：小窗底下打字。问攻略、问规则、提它的头像（它不会接）。
- **球**：设置里可调大小（小 / 中 / 大）；**手机上**靠着屏幕左右边几秒没人碰就**半藏进边里变半透明**，点它、冒气泡、开窗都会出来（设置里可关；电脑上不贴）。
- **独立 API**：设置里填 OpenAI 兼容地址 + Key + 模型（只存浏览器本地）。没填就按顺序找：小狸 Live 填的 → Sugar Baby 手机填的 → 酒馆当前连接。

## 它进不进主线
它只在你脑子里。正文看不见它、看不见走向、看不见积分。**只有两样东西会进下一轮**：你用的注入类道具、你点了「采纳」的走向。都是 once 注入，用完撤。

## 账本存哪
聊天变量 `asu02`（每个聊天一份：绑定状态、称呼、积分、上一回合的走向、签到日期、背包、现编道具、对话记录 50 条）。设置存脚本变量。设置页「解绑」清掉这个聊天的全部账本。

## 改它
- Asu-02 的人设在 `VOICE.voice`，只写 register 不写例句。
- 笑点配方在 `HUMOR`，输出格式和判定规则在 `TURN_FORMAT`，绑定格式在 `BIND_FORMAT`。
- 道具在 `PROPS`（注入类只要改 `text`，`<name>` 会换成玩家 persona 名；嘴替和感知类改 `job`）。分类在 `CATS`，掉率 `DROP_RATE`，新手礼包 `STARTER`，跟上/签到分值 `FOLLOW_PTS` / `SIGN_PTS`。
- 小狮子图标在 `lionSvg()`；贴边逻辑在 `snapNow / unsnap / snapSoon`。

## 没验证的
- 真机（酒馆里）还没跑过，`_测试台.html` 是假酒馆。真机要看：模型会不会老实按「播报：/走向：/跟上：/日期：」的行格式输出（解析是按行前缀，宽松匹配，错一行只丢那一行）；剧情日期同一天会不会被模型换说法（换了会多签一次）；`getCharacter('current')` 在酒馆助手当前版本可用；时光回溯卡靠点 `#chat .mes:last-child .swipe_right`，酒馆 DOM 变了就失效。
